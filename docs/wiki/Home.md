# Duro

Duro – распределённая платформа долговечных объектов для highload-приложений. Разработчик загружает JavaScript-код, создаёт объекты и вызывает методы по постоянному ID. Платформа распределяет работу между нодами, сохраняет состояние и восстанавливает обслуживание после отказов.

Главная задача проекта – масштабировать обработку множества объектов при неравномерной нагрузке. В MVP сравниваем алгоритмы размещения, переносим объекты между исполнителями и проверяем восстановление под нагрузкой.
