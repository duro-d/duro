# Нефункциональные требования

NFR-01–10 обязательны для MVP. Корректность, сохранность, восстановление и highload-проверки входят в приёмку. Рост скорости за счёт потери данных, повторного применения операций или ослабления долговечности недопустим.

| ID | Требование |
| --- | --- |
| [NFR-01](requirements/nonfunctional/NFR-01.md) | Порядок выполнения и целостность |
| [NFR-02](requirements/nonfunctional/NFR-02.md) | Сохранность и восстановление после отказов |
| [NFR-03](requirements/nonfunctional/NFR-03.md) | Хранение состояния, кода и результатов запросов |
| [NFR-04](requirements/nonfunctional/NFR-04.md) | Лимиты и ограничение ресурсов |
| [NFR-05](requirements/nonfunctional/NFR-05.md) | Highload: производительность и масштабирование |
| [NFR-06](requirements/nonfunctional/NFR-06.md) | Доступ и граница доверия |
| [NFR-07](requirements/nonfunctional/NFR-07.md) | Развёртывание и стенд |
| [NFR-08](requirements/nonfunctional/NFR-08.md) | Журналы и метрики |
| [NFR-09](requirements/nonfunctional/NFR-09.md) | Проверяемость и независимость модулей |
| [NFR-10](requirements/nonfunctional/NFR-10.md) | Документация и интеграция |

Численные цели производительности фиксируются под стенд до сравнительных прогонов. Условия и критерии описаны в NFR-05. Эти цели не являются уже полученными результатами.
