# FR-12. Проверить состояние компонентов

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** оператор.

**Вход:** запрос проверки состояния компонента.

**Результат:** работает ли процесс и готов ли он обслуживать обращения.

**Порядок выполнения:**

1. Проверка работы процесса подтверждает, что он отвечает.
2. Проверка готовности учитывает доступность зависимостей: сервис хранения проверяет связь с БД; исполнитель – связь с хранением, возможность загрузки пакетов и работоспособность runtime; маршрутизатор – связь с хранением и наличие готового исполнителя с поддерживаемым runtime. Пустой локальный кеш пакетов сам по себе не означает неготовность.
3. Компонент сообщает статус без пользовательских данных и секретов.

**Приёмка:** работающий процесс без доступа к БД не считается готовым. После восстановления зависимости готовность возвращается. Проверки не меняют объекты.

Связанные сценарии: [UC-08](../../Use-Cases.md#uc-08-восстановить-обслуживание-после-отказа).
