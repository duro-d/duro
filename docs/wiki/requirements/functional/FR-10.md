# FR-10. Обновить версию кода

Обновление кода и функция `migrate` не входят в MVP и его приёмку. В PoC версия объекта фиксируется при создании.

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** разработчик приложения или оператор через API.

**Вход:** `object_id`, целевая `code_version` того же типа и `request_id`.

**Результат:** текущая версия кода и номер ревизии после обновления.

**Порядок выполнения:**

1. Пакет целевой версии заранее загружается и регистрируется по [FR-01](FR-01.md); исполнитель получает его из хранения при подготовке обновления.
2. Duro ставит обновление в очередь объекта и ждёт завершения предыдущего вызова. Проверяет `request_id`; для завершённого повтора возвращает исходный ответ.
3. Если целевая версия уже используется, сохраняет результат запроса и возвращает текущую ревизию без изменения данных и истории.
4. Иначе запускает `migrate` целевой версии с текущими данными и номером прежней версии. Функция проверяет совместимость и записывает преобразованные данные через `storage`.
5. Одной транзакцией сохраняет новую версию кода, изменения данных, следующую ревизию и результат запроса. Запись истории содержит прежнюю и новую версии кода.
6. Пересоздаёт экземпляр. Следующий вызов использует методы новой версии.

```javascript
await duro.updateCode("trip/main", { code_version: "2", request_id: "update-main-v2" });
// При текущей r4 → { code_version: "2", revision: 5 }
```

**Приёмка:** обновление не меняет ID и тип объекта. Новая версия и данные сохраняются вместе. При незавершённом преобразовании остаются прежние код, данные и ревизия. Инициализация не запускается. Старые ревизии сохраняют свои данные и версии кода. Ветки не обновляются автоматически. Обновление создаёт ревизию и при отсутствии записей в `migrate`. После перезапуска объект работает на сохранённой версии. Старый `request_id` возвращает исходный ответ даже после следующего обновления кода и не переключает версию обратно.

Связанные сценарии: [UC-07](../../Use-Cases.md#uc-07-обновить-код-объекта).
