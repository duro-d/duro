# FR-09. Восстановить обслуживание после отказа

Раздел: [Функциональные требования](../../Functional-Requirements.md).

При падении рабочей ноды Duro автоматически назначает доступного исполнителя с новым поколением владения. Новый владелец загружает код и подтверждённые данные. Клиент обращается к прежнему ID; повторяет неподтверждённые вызовы с прежними `request_id`.

**Приёмка:** после остановки до фиксации и после фиксации до ответа объект продолжает обслуживать изменяющие методы. Подтверждённые данные сохраняются, повтор не применяется дважды. Вернувшийся прежний владелец не может записать поздний результат. Переключение primary и отказ VM проверяются по [NFR-02](../nonfunctional/NFR-02.md).

Гарантия относится к сохранённому состоянию. Стек незавершённого метода не продолжается; долговечная очередь неподтверждённых команд не предоставляется.
