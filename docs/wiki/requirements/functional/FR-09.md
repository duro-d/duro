# FR-09. Откатить данные

Дополнительная операция. Отсутствие отката не блокирует приёмку PoC.

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** `object_id`, исходная ревизия `source_revision` и `request_id`.

**Результат:** номер новой ревизии и текущая версия кода.

В PoC откат используется как административная операция. Он заменяет данные на момент своей очереди, включая изменения других клиентов, сохранённые после просмотра исходной ревизии. Демонстрация проводится без параллельного редактирования. Проверка ожидаемой текущей ревизии не входит в контракт операции MVP.

**Порядок выполнения:**

1. Duro ставит операцию в очередь объекта и проверяет сохранённый результат по `request_id`. Завершённый повтор возвращает этот результат.
2. Для нового запроса читает выбранную ревизию. Её версия кода должна совпадать с текущей версией объекта.
3. Заменяет все пользовательские данные данными этой ревизии. Ключи, появившиеся позже, удаляет.
4. Одной транзакцией сохраняет замену, запись истории как следующую ревизию и результат запроса. В записи указывает `source_revision`.
5. Пересоздаёт экземпляр, чтобы он использовал восстановленные данные.

```javascript
await duro.restore("trip/main", { source_revision: 2, request_id: "restore-main" });
// При текущей r3 → { revision: 4, code_version: "1" }
```

**Приёмка:** откат из `r3` к данным `r2` создаёт `r4`, даже если данные совпадают. Все прежние ревизии остаются доступными. ID, тип и версия кода сохраняются. Ветки не меняются. При различающихся версиях кода откат не выполняется; из старой ревизии можно создать ветку по [FR-08](FR-08.md). Операция заменяет данные, актуальные в момент её очереди, без проверки ревизии со стороны клиента. Сохранённые результаты запросов не заменяются. Повтор завершённого отката не создаёт ревизию, а запоздалый повтор прежнего метода возвращает старый ответ без восстановления отменённого изменения.

Связанные сценарии: [UC-06](../../Use-Cases.md#uc-06-вернуть-прежние-данные).
