# FR-03. Получить сведения об объекте

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** `object_id`.

`describe` возвращает ID, тип, закреплённую версию кода, доступные методы. Неизвестный объект даёт `NOT_FOUND`. Чтение метаданных не активирует прикладной код.

**Приёмка:** метаданные соответствуют подтверждённому состоянию. При переносе ID и методы не меняются. Адрес ноды не становится частью клиентского идентификатора.
