# FR-03. Получить сведения об объекте

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** `object_id`.

`describe` возвращает ID, тип, закреплённую версию кода, доступные методы и текущую ревизию. Неизвестный объект даёт `NOT_FOUND`. Чтение метаданных не активирует прикладной код и не создаёт ревизию.

**Приёмка:** версия кода и ревизия относятся к одной подтверждённой версии метаданных. При переносе ID и методы не меняются. Адрес ноды не становится частью клиентского идентификатора.
