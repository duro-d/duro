# FR-03. Получить сведения об объекте

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** `object_id`.

**Результат:** ID, тип, текущие версия кода и ревизия, список RPC-методов. Для объекта с источником также возвращается `origin` с ID источника и номером исходной ревизии.

**Порядок выполнения:**

1. Duro находит объект по ID.
2. Читает его метаданные и список методов его текущей версии кода.
3. Возвращает сведения, относящиеся к одной ревизии.

```javascript
await duro.describe("trip/main");
// → { object_id: "trip/main", type: "TripPlan", code_version: "1",
//     revision: 0, methods: ["addExpense", "replaceExpensePrice", "getSummary"], origin: null }
```

**Приёмка:** список содержит только методы текущей версии. Получение сведений не запускает прикладные методы и не меняет объект.

Связанные сценарии: [UC-02](../../Use-Cases.md#uc-02-вызвать-метод-объекта).
