# FR-02. Создать объект

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** выбранный клиентом `object_id`, тип, версия кода, JSON `input` и `request_id`.

Duro назначает исполнителя, запускает `init(ctx, input)` и атомарно сохраняет начальные данные, метаданные и результат создания. Объект получает ревизию `0`. Повтор с теми же параметрами возвращает прежний результат; другое создание под занятым ID даёт `OBJECT_ALREADY_EXISTS`.

**Приёмка:** два одновременных создания не создают два объекта. Ошибка или таймаут инициализации не оставляют частичное состояние. Предметный отказ запоминается без объекта. Успешно созданный объект после восстановления не проходит `init` повторно.
