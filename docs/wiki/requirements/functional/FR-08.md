# FR-08. Создать ветку

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** ID исходного объекта `source_object_id`, номер его ревизии `source_revision`, ID нового объекта `target_object_id` и `request_id`.

**Результат:** ID ветки, ревизия `0`, версия кода и `origin`.

**Порядок выполнения:**

1. Duro проверяет завершённый результат по целевому ID и `request_id`. Если его нет, проверяет, что целевой ID свободен, затем читает данные и версию кода выбранной ревизии источника.
2. Проверяет, что эта версия зарегистрирована, пакет сохранён и доступен для загрузки исполнителем с подходящей средой исполнения.
3. Создаёт новый объект с тем же типом, этими данными и этой версией кода. Инициализация не запускается.
4. Одной транзакцией сохраняет начальную ревизию `0`, `origin` с ID источника и его ревизией и результат запроса.
5. Возвращает сведения о ветке.

```javascript
await duro.fork({
  source_object_id: "trip/main",
  source_revision: 1,
  target_object_id: "trip/alternate",
  request_id: "fork-alternate"
});
// → { object_id: "trip/alternate", revision: 0, code_version: "1",
//     origin: { object_id: "trip/main", revision: 1 } }
```

**Приёмка:** ветка содержит собственную копию данных. Изменения ветки и источника независимы. Новые изменения источника не влияют на выбранную исходную ревизию. Повтор завершённого запроса возвращает созданную ветку. Занятый другим созданием ID не перезаписывается. Результаты запросов источника не копируются в ветку. Память исполнителя не копируется. Ссылки на другие объекты остаются значениями и не создают копий этих объектов.
