# FR-04. Вызвать RPC-метод

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** `object_id`, имя метода, один JSON-аргумент и `request_id`. Без входных данных передаётся `null`.

Duro возвращает завершённый повтор либо направляет новую операцию владельцу. Исполнитель последовательно выполняет метод, дожидается Promise и передаёт буфер записей и результат на фиксацию. Хранение атомарно проверяет полномочия и повтор, сохраняет данные и ответ.

**Результат:** `{ result }` после долговечной фиксации. Метод без значения даёт `result: null`. Результат сохраняется и при отсутствии записей.

**Приёмка:** метод видит свои `put/delete`; изменение значения без `put` не сохраняется. Два метода одного объекта не изменяют состояние одновременно. Исключение, таймаут и ошибка сериализации не оставляют частичных записей. `ctx.reject` отбрасывает записи и сохраняет предметный отказ. Одновременные повторы применяют изменение один раз. Подробные правила – в [общем контракте](../../Functional-Requirements.md#общие-правила).
