# FR-07. Переносить объекты между исполнителями

Раздел: [Функциональные требования](../../Functional-Requirements.md).

После добавления ноды или обнаружения дисбаланса контроллер может перенести объект. Для воспроизводимых проверок оператор может инициировать тот же перенос вручную. Текущий метод завершается либо его исход разрешается; далее меняются владелец и поколение, целевая нода загружает код и данные.

Во время переноса новые вызовы могут временно не приниматься. Клиент повторяет их с теми же ID. Контроллер ограничивает частоту переносов. Сериализация V8 heap и перенос выполняющегося метода не требуются.

**Приёмка:** ID и состояние сохраняются; старый владелец не может подтверждать новые изменения. Проверяются перенос под нагрузкой, отказ исходной ноды в процессе, время паузы, объём загрузки состояния и влияние на задержки. После успешного переноса новые методы выполняются на целевой ноде.
