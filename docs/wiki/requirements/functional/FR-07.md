# FR-07. Прочитать выбранную ревизию

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** `object_id` и номер `revision`.

**Результат:** полные данные выбранной ревизии и версия кода, действовавшая на ней.

**Порядок выполнения:**

1. Duro находит выбранную ревизию в истории.
2. Восстанавливает данные из сохранённых значений и удалений.
3. Возвращает данные, номер ревизии и её версию кода.

```javascript
await duro.readRevision("trip/main", 1);
// → { revision: 1, code_version: "1", data: { ... } }
```

**Приёмка:** текущие данные объекта не меняются. Прикладные методы не запускаются, время и случайные значения заново не вычисляются. Для чтения достаточно истории; запуск старого кода не требуется.

Связанные сценарии: [UC-04](../../Use-Cases.md#uc-04-просмотреть-историю-и-прошлую-ревизию).
