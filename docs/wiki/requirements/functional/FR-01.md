# FR-01. Зарегистрировать тип и версию кода

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** самодостаточный JavaScript ES module bundle и манифест с типом, версией, `runtime: javascript-v8`, `format: esm`, списком RPC-методов и SHA-256 bundle.

Пакет экспортирует `init(ctx, input)` и `methods`. Duro проверяет манифест, хеш, загрузку в V8 и наличие функций, затем сохраняет пакет. `init` при регистрации не вызывается. Регистрация не создаёт объект.

Одинаковые тип, версия, код и манифест возвращают существующую регистрацию. Другое содержимое под занятой парой даёт `CODE_VERSION_CONFLICT`. Ошибка проверки не оставляет доступного неполного пакета.

**Приёмка:** аукцион и квота загружаются без пересборки или перезапуска рабочих нод. Исполнитель с пустым кешем получает точную зарегистрированную версию. TypeScript заранее собирается в JavaScript; сервер не скачивает зависимости. См. [технические решения](../../Technical-Decisions.md).
