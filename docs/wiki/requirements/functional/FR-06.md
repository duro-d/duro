# FR-06. Размещать объекты по выбранной политике

Раздел: [Функциональные требования](../../Functional-Requirements.md).

Оператор выбирает одну из двух политик: rendezvous hashing или размещение с учётом нагрузки доступных нод. При первом назначении или восстановлении контроллер выбирает исполнителя и закрепляет назначение через модуль состояния.

В MVP нагрузочная политика использует доступные метрики очередей и занятости; точная формула фиксируется автором модуля перед сравнением. Все вызовы направляются закреплённому владельцу, а не случайной ноде на каждый запрос.

**Приёмка:** обе политики проходят одинаковые проверки корректности и нагрузочные сценарии. При изменении состава кластера действующее владение не меняется в обход протокола. Отчёт содержит дисбаланс нагрузки, пропускную способность и задержки; преимущество одной политики заранее не предполагается.
