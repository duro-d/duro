# FR-06. Получить историю

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** `object_id`, размер страницы `limit` и курсор `cursor` для следующей страницы. При первом обращении курсор не передаётся.

**Результат:** записи истории по возрастанию ревизии и курсор продолжения. В каждой записи указаны ревизия, версия кода, выполненная операция, `request_id` и сохранённые изменения. В первой записи находятся начальные данные.

**Порядок выполнения:**

1. При первом обращении Duro запоминает текущую верхнюю ревизию обхода.
2. Возвращает страницу записей до этой границы и курсор.
3. По курсору возвращает следующие записи того же обхода.
4. На последней странице возвращает `cursor: null`.

```javascript
await duro.history("trip/main", { limit: 50 });
// → { entries: [ ... ], cursor: null }
```

**Приёмка:** страницы не пропускают и не дублируют ревизии. Изменения, появившиеся после начала обхода, доступны при новом обходе. Вызовы без записей не добавляются в историю данных. Автор и причина изменения присутствуют только в тех данных, которые записало приложение.
