# FR-05. Прочитать текущие данные

Раздел: [Функциональные требования](../../Functional-Requirements.md).

**Вход:** `object_id`.

`read` возвращает текущее KV-состояние и техническую ревизию через модуль состояния с primary БД. Чтение не создаёт ревизию. При недоступности подтверждённого хранения возвращается ошибка доступности.

**Приёмка:** результат соответствует одной целиком сохранённой версии. Запись, успешно завершённая до начала чтения, видна в результате либо заменена более поздней записью. Старый кеш и отстающая реплика не выдаются за текущее состояние. Чтения прошлых ревизий нет.
