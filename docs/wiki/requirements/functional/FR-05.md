# FR-05. Прочитать текущие данные

Раздел: [Функциональные требования](../../Functional-Requirements.md). Операция подчиняется [общим правилам](../../Functional-Requirements.md#общие-правила).

**Участник:** клиентское приложение.

**Вход:** `object_id`.

**Результат:** полное KV-содержимое объекта, его ревизия и версия кода.

**Порядок выполнения:**

1. Duro читает одну полностью сохранённую ревизию.
2. Возвращает её данные и метаданные без запуска прикладного метода.

```javascript
await duro.read("trip/main");
// → { revision: 1, code_version: "1",
//     data: { budget: 1000, expenses: { train: { amount: 200 } } } }
```

**Приёмка:** ответ не содержит частично выполненных записей. Чтение, начатое после успешного ответа метода, видит его изменения или более поздние. При одновременной записи возвращается целиком состояние до неё или после неё. Чтение не меняет ревизию.

Связанные сценарии: [UC-03](../../Use-Cases.md#uc-03-прочитать-текущие-данные).
