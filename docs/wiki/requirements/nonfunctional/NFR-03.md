# NFR-03. Хранение состояния, кода и результатов запросов

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

В PostgreSQL сохраняются пакеты, метаданные объектов, текущее KV-состояние, технические ревизии, владение и завершённые результаты запросов. После перезапуска нода с пустым кешем получает нужный код и данные из хранения.

История пользовательских версий и ветки не ведутся. Восстановление использует текущее подтверждённое состояние; WAL и репликация остаются внутренними механизмами PostgreSQL.

Для MVP результаты запросов, включая предметные отказы и методы без записей, сохраняются до явной очистки всего тестового набора. Автоматического истечения дедупликации нет. Это ограничение MVP: длительная эксплуатация потребует отдельного контракта очистки. Использование диска и размер таблицы результатов входят в отчёт; оператор контролирует свободное место.

**Проверка:** повтор после смены владельца, перезапуска и переключения БД возвращает прежний результат. Один тип с несколькими версиями не приводит к подмене пакета. Нехватка места не даёт частичного успеха.
