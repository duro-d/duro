# NFR-03. Хранение истории, кода и результатов запросов

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

Все сохранённые ревизии, зарегистрированные версии кода и завершённые результаты запросов хранятся до полной очистки данных развёртывания. Автоматического удаления по сроку нет. Загруженные пакеты кода сохраняются в долговечном хранилище Duro и доступны исполнителям после обычного перезапуска. Локальные кеши можно восстановить из него. Дополнительные операции отката и обновления кода не удаляют старые ревизии и результаты запросов.

Квоты числа и общего объёма ревизий и результатов по объектам не входят в MVP. Доступное место контролирует оператор. Если БД не может сохранить операцию, Duro не возвращает успешный ответ и не удаляет прежние данные ради новой записи. Правила атомарности сохраняются.

Успешный RPC-вызов без записей, например `getSummary`, тоже сохраняет результат запроса. Для чтения текущих данных без такой записи используется `read`.

**Проверка:** после перезапуска доступны старые ревизии, ветка и сохранённые результаты запросов. При отказе записи нет частичных изменений. Для дополнительного отката проверяются чтение прежних ревизий и запоздалый повтор отменённого изменения. Проверка сохранения истории и результатов после обновления кода не входит в приёмку MVP.
