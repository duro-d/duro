# NFR-07. Развёртывание и стенд

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

Локальный Docker Compose запускает три модуля, PostgreSQL, Patroni, etcd и наблюдаемость с закреплёнными версиями и постоянными томами. Допустим отдельный облегчённый профиль для разработки; он не заменяет приёмочный стенд.

Полный стенд размещается минимум на трёх VM. На нём доступны несколько маршрутизаторов и сервисов состояния, минимум три исполнителя, три PostgreSQL-инстанса и три участника etcd. Реплики распределены так, чтобы потеря одной VM оставляла необходимый кворум и путь клиентского вызова. Для NFR-05 пул увеличивается до четырёх исполнителей.

Конфигурация содержит лимиты ресурсов, адреса, политику размещения, параметры HA и способ подключения к текущему primary. Долговечность и синхронная репликация включены. Перед измерениями проверяется фактическая конфигурация, а не только файл настроек.

**Проверка:** запуск по инструкции, загрузка пакета при работающем кластере, перезапуск с сохранением данных, добавление ноды и отказ VM. Контейнеры на одном хосте не считаются проверкой физической независимости реплик.
