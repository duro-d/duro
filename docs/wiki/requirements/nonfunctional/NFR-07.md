# NFR-07. Развёртывание

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

Один документированный сценарий запускает три модуля: маршрутизатор с публичным API, два экземпляра исполнителя с runtime и сервис хранения. PostgreSQL с постоянным томом запускается отдельно. Затем демонстрационный скрипт или CLI загружает пакет кода, создаёт объект и вызывает его методы. Пакет не включается в образы исполнителей. Отдельный пользовательский интерфейс не требуется. Версии зависимостей закреплены. Для работы уже собранного стенда не нужна облачная учётная запись или платный сервис.

**Проверка:** разработчик запускает стенд по README за 30 минут без учёта скачивания и сборки. Остановка и обычный повторный запуск сохраняют данные. Полная очистка данных выполняется отдельным явным действием.

Связанные сценарии: [UC-01](../../Use-Cases.md#uc-01-подключить-тип-и-создать-объект), [UC-08](../../Use-Cases.md#uc-08-восстановить-обслуживание-после-отказа).
