# NFR-08. Журналы и метрики

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

Сервисы пишут структурированные JSON-журналы. Для вызова доступны `request_id`, `object_id`, тип операции, ID ноды, поколение, длительность и результат. Для переноса и восстановления – исходная и целевая ноды, причина и длительность. Тела запросов, состояние и секреты по умолчанию не записываются.

Prometheus собирает счётчики запросов и ошибок, гистограммы задержек, очереди, активные объекты, CPU/RAM, задержки хранения, переносы и восстановления. `object_id` и `request_id` не используются как метки временных рядов: количество объектов не должно раздувать мониторинг. Подробности конкретного объекта ищутся в журналах.

**Проверка:** dashboard Grafana показывает картину нагрузки и внесённых отказов. Исходные метрики позволяют сопоставить успешные операции, отказы и повторы. События смены владельца видны на одной временной шкале с задержками.
