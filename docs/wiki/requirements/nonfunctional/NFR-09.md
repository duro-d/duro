# NFR-09. Проверяемость и независимость ядра

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

Автоматизированные проверки запускаются одной командой. Они проверяют последовательное выполнение, атомарное сохранение нескольких записей, предметный отказ и исключение после `put`, одновременные повторы с одинаковым `request_id`, конфликт содержимого запроса, историю, ветку и остановку исполнителя. Отдельно проверяются таймаут с поздним результатом и запрет записи прежним владельцем.

Дополнительный откат проверяется при его реализации. Проверки обновления кода, преобразования данных и отказа преобразования не входят в приёмку MVP.

**Проверка:** пакеты плана поездки и счётчика с ограничением загружаются через API без изменений образов или перезапуска серверов. Оба типа используют только KV-интерфейс `storage` и поддерживают обязательные операции с объектом. Проверяются результат метода, отсутствие значения с `result: null`, ошибка сериализации без частичных записей и активация на исполнителе с пустым кешем пакетов. Остановку до сохранения и после сохранения до ответа можно воспроизвести в тесте.
