# NFR-06. Доступ и граница доверия

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

MVP обслуживает одно доверенное приложение. Внешний API требует токен развёртывания; права пользователей приложения проверяет прикладная логика. Внутренние gRPC-интерфейсы доступны только участникам стенда.

Runtime предоставляет стандартный JavaScript и контекст Duro. Обработчики не получают сеть, файловую систему, фоновые задачи или API других объектов. Пакет самодостаточен; загрузка внешних зависимостей на ноде отключена.

**Проверка:** без токена внешний API отклоняет запрос, повреждённый пакет не регистрируется, запрещённые host API недоступны. Токены и полные данные объектов не попадают в журналы. Изоляция недоверенных арендаторов и полноценная модель безопасности публичного хостинга находятся вне MVP.
