# NFR-06. Доступ

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

API загрузки пакетов и работы с объектами требует токен развёртывания. Токен даёт доступ ко всем объектам одного приложения. Права отдельных пользователей проверяет приложение.

Секреты передаются через окружение или отдельный файл. Их нет в репозитории и журналах. По умолчанию API принимает соединения только с loopback-интерфейса, служебные порты наружу не публикуются. Для внешнего доступа инструкция описывает настройку TLS.

**Проверка:** без действительного токена нельзя читать данные, вызывать методы, создавать объекты или менять код. Проверка состояния без токена, если она доступна, возвращает только статус.
