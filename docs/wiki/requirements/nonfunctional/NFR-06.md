# NFR-06. Доступ и граница доверия

Раздел: [Нефункциональные требования](../../Nonfunctional-Requirements.md).

MVP обслуживает одно доверенное приложение. Внешний API требует токен развёртывания; права пользователей приложения проверяет прикладная логика. Внутренние gRPC-интерфейсы доступны только участникам стенда.

Runtime предоставляет стандартный JavaScript и контекст Duro. Обработчики не получают сеть, файловую систему, фоновые задачи или API других объектов. Пакет самодостаточен; загрузка внешних зависимостей на ноде отключена.

Ограничения распространяются на методы и `init`. `ctx.storage` привязан к текущему объекту, в том числе при размещении нескольких объектов на одной ноде. ID другого объекта разрешён как обычное JSON-значение, но не предоставляет доступ к его состоянию или методам.

**Проверка:** без токена внешний API отклоняет запрос, повреждённый пакет не регистрируется, запрещённые host API недоступны в методах и `init`. Два объекта с одинаковыми именами ключей имеют независимые данные; сохранение чужого ID не открывает доступ к чужому состоянию или методам. Токены и полные данные объектов не попадают в журналы. Изоляция недоверенных арендаторов и полноценная модель безопасности публичного хостинга находятся вне MVP.
