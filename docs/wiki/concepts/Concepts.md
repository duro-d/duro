# Концепции Duro

Duro предоставляет множество объектов с постоянными ID, JavaScript-кодом и собственным долговечным состоянием. Рабочие ноды выполняют методы, модуль состояния фиксирует результат, маршрутизация управляет размещением и восстановлением.

Highload определяет основные задачи: распределение неравномерной нагрузки, ограничение очередей и памяти, эффективная фиксация и восстановление под нагрузкой.

## Термины

| Термин | Значение |
| --- | --- |
| Объект | Логическая сущность с ID, типом, закреплённой версией кода и данными |
| Экземпляр | Загруженное на рабочей ноде представление объекта; может исчезнуть и быть создано заново |
| Рабочая нода / исполнитель | Rust-процесс, обслуживающий множество объектов |
| Владелец | Исполнитель, имеющий право подтверждать изменения объекта |
| Поколение / epoch | Номер владения; защищает от записи прежнего владельца |
| Ревизия | Номер подтверждённого состояния; используется при фиксации |
| Активация | Загрузка кода и сохранённых данных для исполнения методов |
| Перенос | Смена владельца с загрузкой состояния на целевой ноде |
| `request_id` | Идентификатор одной операции, сохраняемый при повторах |

Разработчик определяет правила приложения и явно пишет данные через `storage`. Duro определяет порядок исполнения, назначает владельца и подтверждает запись. Подробный контракт — в [требованиях](../Requirements.md).
