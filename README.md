# Duro

Распределённая платформа долговечных объектов для highload-приложений. Разработчик загружает JavaScript-код и вызывает методы по постоянному ID; платформа управляет размещением, сохранением состояния и восстановлением после отказов.

Проект находится на этапе разработки MVP. Документация описывает целевую модель и критерии приёмки.
